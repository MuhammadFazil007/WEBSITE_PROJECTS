📌 JSON Key Takeaways:

  • JSON.stringify(obj) → Object to JSON string
  • JSON.parse(str) → JSON string to Object
  • Reviver function → Parse karte waqt data transform kar sakte ho
  • Deep Clone → JSON ka use karke objects ka deep copy bana sakte ho (but Date/Function lost!)
  • API Communication → 95% modern APIs JSON format use karti hain
