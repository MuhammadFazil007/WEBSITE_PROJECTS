About This Project

The Aircraft Information Management System is a semester project developed for the Web Technology course. This website demonstrates the practical application of fundamental web development technologies.

Project Objectives

This project aims to create a user-friendly platform for aviation enthusiasts, students, and learners to explore aircraft information in an organized and interactive manner.

Technologies Used

HTML5 — Structure
CSS3 — Styling
JavaScript — Interactivity
localStorage — Persistence

Key Features

✅ User login & registration system
✅ Browse aircraft catalog
✅ Search and filter functionality
✅ Add aircraft with photo uploads
✅ Persistent data across sessions
✅ View detailed aircraft specifications
✅ Responsive design for all devices

Target Audience

• Aviation enthusiasts
• University students
• Beginners interested in aircraft
• Academic instructors
